# AI 자동화 구상 도우미 (1단계 시범)

중소 제조기업의 AI 전환을 학생이 선정→관찰→판별→구상→브리핑→전환 6단계로 돕는 웹 도구입니다.
AI는 초안만 내고, 판별·구상은 학생이, 채택은 대표가, 최종 선정은 심사위원회가 정합니다.

## 사용
`index.html` 하나로 동작합니다. GitHub Pages로 열거나 파일을 브라우저로 바로 열면 됩니다. 처음 열면 시연용 예시 데이터(가상 기업·학생)가 들어 있습니다.

## 데이터 원칙
- 작업 원문, 공정 수치, 인건비, 이름은 브라우저(회사 PC)의 localStorage에만 저장됩니다. 서버로 보내지 않습니다.
- 정부 제출용 기록은 기업 동의 시에만, 비식별 6개 항목(후보 분야, 판별 결론, 채택 여부, 전환 결과, 회수 기간 범주, 걸린 기간)으로 만듭니다.
- AI 초안 기능은 claude.ai 아티팩트 안에서만 동작합니다. 이 사이트에서는 '직접 작성 모드'로 열립니다. 상용 AI 기업용 계정을 붙이려면 API 키를 숨기는 중계 서버가 필요합니다.
